Fixed in app-store-reviews-scraper build 0.1.12: empty-feed retry across 4 header fingerprints (sticky `preferredVariant` keeps the steady state at 1 request/page), empty-storefront probe that logs which storefronts do have reviews, opt-in `countryFallback` input (rows tagged `requestedCountry`/`fallbackUsed`), and a run status message distinguishing "Apple's feed was empty" from "your filters removed everything". Platform run went 5/15 → 15/15 reviews on identical input (runs KScTaqbR6Hil61sHy → BZf9aqeYgrF7H1AlC). Committed `398143f`. Full detail in LEARNINGS.md.
