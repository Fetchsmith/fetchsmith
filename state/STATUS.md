- **Free improvement while in there (0.1.34):** `detailLevel:"full"` already fetches `/products/<handle>.js`, which always carries a real `available` flag — so full-detail runs now resolve leftover unknowns from it at **no extra request**. Only fills nulls, never overrides a flag the base route shipped.
