**Field-for-field, `JobsFlow` is a narrower, less structured product than its "most comprehensive" pitch claims (checked live 2026-10-05, its own README and input schema).** It reads **3 boards — Remote OK, Remotive and We Work Remotely** — not seven; We Work Remotely was added here at cycle 1319, so all 3 of its boards now overlap this Actor's 7, meaning its coverage is a strict subset, not a superset. Its output is 8 fixed fields with `salary` as a single **unparsed string "if provided"** — no `salaryMin`/`salaryMax`/`salaryCurrency`/`salaryPeriod`, so a buyer filtering or sorting by pay has to parse free text themselves, the exact problem this Actor's normalized salary fields exist to remove. Its input is 3 parameters (`searchKeywords`, `techStack`, `maxJobs`) with no date window, no job-type or seniority filter, no salary floor, and no watch/schedule-diff mode — a scheduled run re-delivers and re-bills the entire matching set every time, where this Actor's `watchLabel` only charges for what changed. Its "intelligent de-duplication" claim publishes no method and no measured rate, unlike the company-suffix-stripped match and the 10-of-250 measured overlap documented above. At 65 users / 39 new in the last 30 days (unchanged from the count cycle 1232 recorded one day earlier, so this specific snapshot shows a pause, not continued compounding — worth re-checking in a future cycle before treating the growth as still steepening), the honest read is: it is winning on price and on boards neither of us already had the user's attention for, not on completeness — the "most comprehensive" claim in its own listing is not true against this Actor's schema or input surface.
