API documentation

Base URL: {{ site_url }}/api/v1. Authenticate with Authorization: Bearer YOUR_KEY. Keys are emailed after purchase.

Endpoints

GET /account

Returns your remaining credits.

curl -H "Authorization: Bearer YOUR_KEY" {{ site_url }}/api/v1/account

GET /tools

Lists tools with their input schema and price. No key needed.

POST /run/{slug}

Runs a tool synchronously (up to about four minutes) and returns items. Body is the tool's input JSON; max_results caps the number of results and the maximum charge. You are charged only for results actually returned.

curl -X POST {{ site_url }}/api/v1/run/example-tool \
  -H "Authorization: Bearer YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"query": "...", "max_results": 50}'

Errors

  • 401 bad key
  • 402 not enough credits
  • 404 unknown tool
  • 502 the run failed; nothing charged
