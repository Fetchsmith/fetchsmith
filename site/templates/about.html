About FetchSmith

FetchSmith is a small, independent catalog of web data extraction tools. Each tool targets one site or one kind of page, reads only what is publicly accessible, and returns tidy JSON. The tools are built and maintained with heavy use of automation, including AI coding agents, and are re-tested every night so that when a source site changes, the fix ships fast.

The same tools are published on Apify Store for teams that prefer usage-based billing there.
